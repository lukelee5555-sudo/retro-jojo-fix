# 조조전 웹 실행기 (BGM 패치판)

삼국지 조조전 계열(조조전 3.0F · 영걸전 RED · 신조조전 7.0 · 소오강호전 · 영걸복한록 · 원판 조조전)의 원본 윈도우 실행 파일을 브라우저 안에서 그대로 돌리는 **한 파일짜리 웹 실행기**입니다. 아이폰 사파리에서 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 바로 열기

**https://lukelee5555-sudo.github.io/retro-jojo-fix/**

1. 사파리로 위 주소를 연다
2. 공유 → **홈 화면에 추가**
3. 홈 화면 아이콘 실행 → `zip 고르기` → 게임 폴더를 묶은 zip 선택
4. 타이틀 화면을 한 번 터치하면 BGM이 재생된다

자세한 사용법과 세이브 옮기기는 [설치안내.md](설치안내.md).

## 2026-11-20 (BGM 패치)

- mp3를 타입 없는 blob으로 넘겨 Safari가 디코딩하지 못하던 문제 → 확장자에 맞는 MIME(`audio/mpeg` 등) 지정
- 첫 재생이 사용자 제스처 밖에서 일어나 iOS가 막으면 다시 시도하지 않던 문제 → 실패 시 플래그 유지 + `pointerdown`/`touchstart`/`keydown`마다 재시도, 미디어 오류 시 `load()`
- `<audio>`를 DOM에 붙이고 `preload="auto"`, `playsinline` 지정
- 게임 폴더에 `SoundTrk`(BGM)가 없으면 화면에 안내 표시
- 첫 화면 판 표기: `판: 2026-11-20 (BGM 패치)`

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 실행기 전체(에뮬레이터 + UI). 외부 의존성 없음 |
| `sw.js` | 실행기 껍데기만 캐시(오프라인 실행). 게임 파일·세이브는 건드리지 않음 |
| `manifest.webmanifest` | 홈 화면 추가용 매니페스트 (상대 경로) |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 아이콘 |

## 알아둘 점

- 게임 데이터(ROM·게임 폴더)는 이 저장소에 포함되어 있지 않습니다. 각자 가진 파일을 기기에서 골라 쓰는 방식이고, 실행기는 그 파일을 읽기만 하며 아무것도 업로드하지 않습니다.
- 세이브·상태 저장은 브라우저(IndexedDB)에 남습니다. 주소가 바뀌면 새로 시작되므로 내보내기/가져오기로 옮깁니다.
- GitHub Pages 정적 호스팅이라 서버·계정·설치가 필요 없습니다.

## 라이선스 / 권리

실행기 코드는 저장소 주인(은석)이 사용·수정할 수 있습니다. 게임 자체의 저작권은 각 권리자(KOEI 등)에게 있으며 이 저장소는 게임 파일을 배포하지 않습니다.
